# New Theme

A lightweight, clean, and responsive custom-built WordPress blog theme engineered from scratch using PHP, HTML5, CSS3, and vanilla JavaScript.

---

## 🚀 Tech Stack
* **Platform:** WordPress
* **Languages:** PHP, HTML5, CSS3, JavaScript (ES6)
* **Development Environment:** Local server (XAMPP / LocalWP), Visual Studio Code

---

## ✨ Features
* Clean, semantic HTML5 structure for optimal performance.
* Comprehensive WordPress template architecture supporting custom front pages, archives, searches, and single posts.
* Modular organization utilizing helper functions, classes, and reusable template parts.

Installation & Setup
You can install this theme using one of two methods depending on your workflow:

Method 1: Manual Installation (Local Development)
Clone or download this repository.

Place the unzipped theme folder directly into your local WordPress themes directory:
wp-content/themes/newtheme/

Log in to your WordPress Admin Dashboard.

Navigate to Appearance > Themes.

Locate New Theme and click Activate.

Method 2: Upload via WordPress Dashboard (ZIP)
Compress your newtheme directory into a .zip file.

Log in to your WordPress Admin Dashboard.

Navigate to Appearance > Themes and click Add New Theme.

Click Upload Theme, select your .zip file, and click Install Now.

Once installed, click Activate.
